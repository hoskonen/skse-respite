# Respite

Respite is an SKSE plugin for Skyrim Special Edition that aims to provide more control over music pacing and playback behavior.

The initial goal is to introduce configurable periods of silence between exploration tracks, allowing Skyrim's soundtrack to feel less continuous and more atmospheric.

Planned functionality may include:

- Configurable delays between music tracks
- Different pacing rules for exploration, dungeons, towns, and other music types
- Improved handling of music transitions around combat
- Repeat prevention and additional soundtrack pacing controls

The project is currently in early development.
